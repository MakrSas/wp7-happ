# Happ для Windows Phone 7.8 (HTC HD7)

VPN-клиент для подписок Happ / Remnawave. В WP7 нет VPN API, поэтому Happ работает как прокси на самом
телефоне: фоновый процесс `happd.exe` принимает соединения и отправляет их на сервер провайдера по протоколу
**Trojan поверх TLS 1.3**. Браузер и приложения ходят через него по прокси Wi-Fi, который Happ включает и
выключает сам.

## Что умеет

- **Подписка**: загрузка с заголовками Happ (`User-Agent`, `x-hwid`), иначе панель Remnawave отдаёт заглушку
  «App not supported». Понимает JSON-конфиги Xray и списки ссылок `trojan://` / `vless://`.
- **Серверы**: разделы подписки, страна из флага, пинг (TCP + TLS). Работают Trojan-серверы (TCP + TLS),
  VLESS Reality и gRPC пока только видны в списке.
- **Прокси Wi-Fi автоматически**: включите прокси в сети один раз руками, дальше Happ ставит его при включении VPN,
  убирает при выключении и обновляет адрес телефона.
- **Современный HTTPS в IE**: IE9 умеет только TLS 1.0. Happ говорит с IE по TLS 1.0 (BearSSL) сертификатом
  своего корня, а с сайтом — по TLS 1.2/1.3 (mbedTLS) с настоящей проверкой сертификата. Корневой ключ RSA-2048
  создаётся на телефоне; сертификаты подписаны SHA-1, потому что WP7 SHA-2 в сертификатах не понимает.
- **Локальная сеть идёт напрямую**: `192.168.*`, `10.*`, `172.16–31.*`, `*.local`, имена без точки.
- **Работает в фоне**: `happd.exe` живёт и при закрытом приложении. Если прошивка не даёт запустить процесс,
  прокси работает потоком внутри приложения.

## Установка

Нужен interop unlock (как для SIM-эмулятора).

1. Поставить `release/HappWP-<версия>.xap`.
2. Happ → «настройки» → ссылка на подписку → «обновить подписку».
3. «серверы» → выбрать Trojan-сервер → «подключение» → VPN: вкл.
4. Один раз: Настройки → Wi-Fi → сеть → прокси: вкл, сервер — адрес телефона из Happ, порт 10809.
   **Не `127.0.0.1`**: WP7 молча игнорирует прокси на loopback.
5. Happ → «настройки» → «установить сертификат» → в IE «установить сертификат».

## Как устроено

| Часть | Что делает |
|---|---|
| `native/plat.c` | сокеты, потоки, энтропия (Linux и WinCE) |
| `native/tunnel.c` | TLS (mbedTLS 3.6) и Trojan; TLS поверх туннеля для перехвата |
| `native/proxy.c` | HTTP (CONNECT и полный URL) и SOCKS5 на одном порту, обход локальной сети, страница сертификата |
| `native/ca.c`, `native/mitm.c` | корень Happ, выпуск сертификатов, BearSSL-сервер для IE |
| `native/https.c` | HTTPS GET для подписки |
| `native/wifiproxy.c` | прокси Wi-Fi: `HKLM\Comm\PROXYDATABASE\<SSID в hex>\1` |
| `native/happd_ce.c` | фоновый процесс `happd.exe` |
| `native/happ_native.c` | `HappNative.dll` (ComBridge): реестр, запуск движка, пинг, подписка, проверка |
| `app/` | приложение Silverlight 7.1 в стиле метро |

Ядро собирается и под Linux (`./build.sh remote linux`), чтобы проверять его на настоящих серверах с s8build
(`tools/sub_pick.py` достаёт Trojan-серверы из подписки, не печатая паролей).

```
./build.sh remote xap            # отладочная сборка
./build.sh remote xap release    # релиз → release/HappWP-<версия>.xap
```

## Ограничения

- Только Wi-Fi: прокси в WP7 есть только у Wi-Fi-сетей.
- Через прокси идут приложения, которые уважают системный прокси (IE, большинство Silverlight-приложений).
- Сайты всё равно видят IE9 по `User-Agent` и отдают ему старые версии страниц; YouTube не пускает вовсе.
